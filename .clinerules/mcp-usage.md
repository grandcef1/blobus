# MCP Usage Guidelines для Blobus

## Когда использовать Supabase MCP
- При создании/изменении таблиц в БД
- При написании RLS policies
- При генерации TypeScript типов из БД
- При работе с Edge Functions
- НЕ использовать для простых SELECT queries в коде

## Когда использовать Figma MCP
- При реализации нового UI компонента
- При изменении существующего компонента
- Для проверки spacing, colors, typography
- НЕ использовать если компонент уже есть в коде

## Когда использовать Context7
- При использовании новой библиотеки
- При обновлении версии React/Framer Motion
- Когда не уверен в API
- НЕ использовать для базовых вещей

## Когда использовать Playwright/Chrome DevTools
- После создания нового UI компонента
- Для проверки accessibility
- Для тестирования анимаций
- НЕ запускать на каждый коммит

## Когда использовать Exa/Perplexity
- Для сложных архитектурных решений
- Для исследования best practices
- НЕ использовать для простых вопросов (спроси у меня)

## Общие правила
- НЕ вызывай MCP для каждой мелочи
- Если можешь ответить без MCP — отвечай без MCP
- Кэшируй результаты MCP если они не меняются
