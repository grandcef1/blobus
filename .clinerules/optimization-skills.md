# Optimization Skills (Caveman voice + Ponytail + Graphify workflow)
> Приоритет: project-rules.txt переопределяет этот файл. Здесь только специфика экономии токенов/контекста. Не дублировать §5.3 (no any) и §9.1 (frontend-first) — они уже в project-rules.txt.

## Graphify — query-first (экономия контекста)
- Перед чтением нескольких файлов — запрос к локальному графу через терминал:
  `graphify query "<вопрос>"` / `graphify explain "<символ>"` / `graphify path "A" "B"`.
- Граф = tree-sitter по коду (локально, без LLM/сети). НЕ включать семантический/vision-проход.
  НЕ включать git post-commit hook и MCP-сервер.
- graphify-out/ не коммитить.
- Если графа нет или запрос пуст — читать файлы точечно, НИКОГДА не весь src/ в контекст.

## Caveman voice — Say less (экономия выходных токенов)
- Формат: `[что сделано] [почему — 1 строка]. [следующий шаг].` Без приветствий и пересказа запроса.
- Сохранить §14 project-rules.txt: одна строка обоснования подхода = это «почему, 1 строка»; конфликта нет.
- Payload verbatim: код, пути, команды, сообщения ошибок — символ в символ.
- Read-less через Go-бинарник НЕ применять (harness не ложится на Cline); шум режем форматом выше.

## i18n — все строки через словарь (обязательно)
- Все НОВЫЕ UI-строки идут через `t()` и ключи в `src/locales/{ru,en,es}`; захардкоженный текст запрещён.
- Три языка: `ru` (эталон типов), `en`, `es`. Пространства имён: `common`, `landing`, `footer`, `auth`.
- Ключи типизированы по ru-словарю (`CustomTypeOptions` в `src/lib/i18n.ts`): опечатка в ключе — ошибка сборки.
- Текст в компоненте — только `t('...')`; в данных (`*.data.ts`) — ключи, а не строки.
- Функции-валидаторы возвращают ключ словаря, а не текст: перевод делает компонент.
- Не переводить: имена брендов, соцсетей, режимов (Interview Prep), образцы английской речи, мок-данные уроков.
